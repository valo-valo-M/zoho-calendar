# Zoho Calendar

Userscript for displaying the Zoho Creator calendar as a vertical mobile weekly list.

## Files

- `zoho-calendar.user.js` — complete userscript
- `zoho-calendar.meta.js` — metadata used to check for updates

## Installation

Install `zoho-calendar.user.js` in the Userscripts extension in Safari.

The script is configured to check the metadata file at:

`https://raw.githubusercontent.com/valo-valo-M/zoho-calendar/main/zoho-calendar.meta.js`

After publishing a new version, increase `@version` in both files.
